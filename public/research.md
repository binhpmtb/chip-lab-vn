# Research and integration decisions

Reviewed on 17 November 2026 using upstream repositories and project documentation. This is the pre-implementation research record. Versions and shipped files must also be recorded in the release notices.

## Architecture selected

Next.js with TypeScript and static export will deliver lessons and the application on Vercel. CodeMirror will provide the editor. Icarus Verilog WebAssembly from VeriSim will compile and execute testbenches in a disposable Web Worker. YoWASP Yosys will synthesize RTL in a separate worker. netlistsvg will render actual Yosys JSON. Tools load on demand with visible status and workers can be terminated on timeout. Progress is stored locally. Lesson text is original bilingual Markdown under `content/`.

The application source will use GPL-compatible licensing. Redistributed Icarus binaries require their license, corresponding source, patches and build instructions. A worker boundary does not remove those distribution obligations. Grading testbenches can be hidden from the normal editor, but browser-delivered code remains inspectable. Exercises are educational self-checks.

## Release implementation checklist

The shipped diagram dependencies are pinned to netlistsvg 1.0.2 and elkjs 0.12.1. netlistsvg is rebuilt from its official npm source with the published lockfile. elkjs 0.12.1 declares EPL-2.0 OR GPL-3.0-or-later. The older ELK bundle supplied by VeriSim had an EPL-1.0 header and was replaced. The replacement combination successfully renders the digital example to SVG. Build instructions and source archives are published under `/source/`, and full collected notices under `/third-party-notices.txt`.

The implemented engine uses `@yowasp/yosys` version `0.66.1164`, whose version output identifies Yosys revision `86f2ddebc`. Its WASM and resource files are self-hosted. Icarus assets come from VeriSim revision `ab0ff386` and the matching Icarus source is `c7530db`. Corresponding source, build patch and instructions are provided under `public/source/`. The example library includes Alex Forencich's MIT-licensed UART transmitter from `verilog-uart` revision `1b867e53af738e4a8bc7c839ca2f1c07f40382dc`, with its notice retained. These records describe the initial implementation and should be updated when assets change.

- Pin dependencies and store the lockfile.
- Record the exact VeriSim revision and matching Icarus source/patch/build script, retaining all license files.
- Preserve copyright and license text for distributed MIT, ISC, BSD and EPL components.
- Make Credits reachable from the app, identifying authors, upstream links, versions and local notices.
- Keep educational references distinct from bundled runtime dependencies in the credits data.
- Test actual Verilog compilation, VCD output, synthesis JSON and a deliberately failing submission.
- Treat unavailable source licenses as link-only resources until verified.
- Keep original lesson writing and original exercises under the app's stated license.
